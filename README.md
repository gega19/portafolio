# Portafolio — Corporación CEG

Showcase de proyectos (React + Vite + TypeScript + Tailwind).

## Requisitos

- Node.js 20 o superior (ver `.nvmrc`)

## Desarrollo

```bash
npm install
npm run dev
```

Abre la URL que muestre la terminal (por defecto `http://localhost:5173`).

## Producción

```bash
npm run build
npm run preview
```

## Variables de entorno

No son obligatorias. Copia `.env.example` a `.env` si quieres el archivo local; para claves futuras usa prefijo `VITE_` y documenta en `.env.example`.

## Despliegue (Vercel)

Proyecto listo para Vercel: salida `dist`, ver `vercel.json`.
